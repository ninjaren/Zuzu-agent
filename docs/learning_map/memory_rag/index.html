🧠 記憶與 RAG

LLM 沒有記憶力。本專案用「短期記憶＋長期向量記憶」兩套機制組合出記憶的效果，每次對話前合併送進去——拆開來看，兩個都不複雜。

建議學習順序：
  1. ① 短期記憶 —— 最簡單的記憶：直接把最近幾輪對話重講一次給大腦聽
  2. ② 長期記憶 —— 用向量資料庫存住「所有」對話，用語意搜尋找回相關的
  3. ③ RAG 檢索整合 —— 兩種記憶怎麼在 build_messages() 合併成最終送給 LLM 的內容
  4. ④ RAG 評估方法論 —— 組起來之後，怎麼知道它夠不夠準、幻覺多不多，又不用養一整個專家審核團隊
