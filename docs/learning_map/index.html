🔗 核心鏈路

點擊節點看詳細說明，建議依照 ①→⑦ 的順序走一遍。每一站都對照 qwen3_8b 專案的實際程式碼，不是空談概念。

建議學習順序：
  1. ① LLM 大腦 —— 先理解它只是「輸入文字→輸出文字」的函式，沒有手腳沒有記憶
  2. ② LLM ⇄ Harness 橋接 —— API、Tokenizer、工具呼叫格式怎麼讓大腦跟身體對話
  3. ③ Harness 身體 —— 真正執行工具、跑迴圈、把關安全的那層程式
  4. ④ 雙向溝通 —— Harness 怎麼來回傳遞資訊，不是單向下命令
  5. ⑤ 自我檢查機制 —— 本專案 qwen3_8b 實際用的驗證做法
  6. ⑥ Harness ⇄ MCP 橋接 —— MCP Client、傳輸線、JSON-RPC
  7. ⑦ MCP 插頭規格 —— 統一工具接頭，讓 harness 能接上任何標準化工具
